# 환자별 전체 진료 기록

진료 관리에서 환자를 선택한 뒤 오른쪽 `이 환자의 전체 진료 기록`을 펼칩니다.
날짜와 담당 의사 제한 없이 해당 환자의 모든 방문을 최신 접수일시·ID 순으로 25건씩 조회합니다.
현재 방문과 대기/진료 중/완료/취소 상태를 모두 포함합니다.

방문을 선택하면 당시 방문 사유, SOAP, 진단, 처방을 조회 전용으로 표시합니다.
현재 작성 중인 SOAP·진단·처방·검사/처치 요청은 별도로 유지됩니다.
다른 환자로 전환하면 이전 기록을 지우며, 늦게 도착한 이전 환자/방문의 응답은 적용하지 않습니다.
저장된 기록을 다시 확인하려면 `기록 새로고침`을 누릅니다.

- `GET /api/clinic/patients/{id}/encounters?page=0`: 방문 요약 페이지. 상세 내용은 목록에 싣지 않습니다.
- 기존 `GET /api/clinic/encounters/{id}`: 선택한 방문의 상세 기록.
- 기존 진료 조회 권한(의사·간호사·관리자)을 적용합니다.
- 별도 테이블 추가 없이 `encounters`를 환자 ID로 조회합니다.
