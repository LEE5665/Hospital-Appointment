# 상병마스터 초기화

`배포용 상병마스터.xlsx`를 classpath에서 읽어 백엔드 시작 시 초기화합니다.
기존 계정 유무와 관계없이 실행하며, `diagnosis_codes`에 데이터가 있으면 파일을 다시 읽지 않습니다.

- `상병분류기호(완전코드)` 시트만 사용합니다. 전체/삭제/신설/정오 시트는 합치지 않습니다.
- `diagnosis_codes`: 코드당 한 행. 파일에서 처음 나온 명칭과 부가정보를 보관합니다.
- `diagnosis_terms`: 같은 코드의 다른 명칭을 포함한 모든 원본 명칭과 엑셀 행 번호를 보관합니다.
- 완전코드/주상병사용 구분은 파일 안내대로 `N`이면 false, 공란이면 true입니다.
- 성별은 원본 `X`(여성), `Y`(남성), 공란을 보존합니다. 연령 공란은 null입니다.
- 완전코드만 저장하며, 해당 시트에 불완전코드가 발견되면 검증 오류로 중단합니다.
- 현재 파일 기준 코드 41,660개, 명칭 72,822개입니다.
- 현재 파일의 분류 버전은 KCD-9이며 3차 정오 반영본입니다. 대표 정보는 첫 행, 추가 명칭은 별도 행으로 보존합니다.

POI 스트리밍 방식으로 필요한 시트만 읽고, 500행씩 DB에 배치 저장합니다.
전체 적재는 한 트랜잭션이므로 읽기/검증/저장 실패 시 일부만 남지 않습니다.
실패는 시작 오류로 표시되며, 원인을 수정하고 재시작하면 다시 적재됩니다.
여러 서버의 최초 동시 기동은 피하고 한 인스턴스에서 초기화를 마친 후 나머지를 시작하세요.

설정(기본값):

```properties
clinic.diagnosis.init.enabled=true
clinic.diagnosis.init.resource=classpath:data/배포용 상병마스터.xlsx
clinic.diagnosis.init.version=KCD-9
```

파일 교체만으로 기존 데이터를 덮어쓰지 않습니다. 이후 버전 변경은 과거 환자 진단과의 연결을 고려한 별도 마이그레이션으로 처리해야 합니다.
이전 전체 시트 방식으로 이미 초기화한 DB도 자동 삭제하지 않습니다. 기존 데이터가 있다면 진단 선택 시 `complete_code=true`로 제한하고, 필요 시 별도로 정리해야 합니다.
이 기능은 기준 목록 초기화이며 진단 검색 API와 환자별 진단 등록은 별도입니다.
